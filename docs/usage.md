# 使い方

## キー操作

| キー | 動き |
|---|---|
| 英字・記号 | 未確定の文字列に足す。打っている途中も変換して表示する。日本語の区間は変換し、英語の区間は英字で表示する |
| Space | 打っている途中は空白を入れる。空白は英語の区間に入り、打ったまま残る。文節を選んでいる間は Shift+Space と同じ |
| Shift+Space | 文節に区切って最初の文節を選ぶ。もう一度押すと候補の窓を出し、その後は次の候補へ進む |
| ↓ / ↑ | 次の候補 / 前の候補 |
| ← / → | 選んでいる文節を縮める / 伸ばす。日本語は 1 かなずつ、英字は 1 文字ずつ。隣の英語・日本語も取り込め、読めない英字を含むと英字のまま残る。区間をまたいで日本語を取り込むときと、区間をまたいで伸ばした文節を縮めるときは、読み切れる綴りずつ（`tte` は `って`）。伸ばした後に縮めると、手放した英字は英字に戻る。句読点と記号は 1 つずつ取り込み、取り込んだ文節は 1 つの文節として変換する（`(cafe)` を（カフェ）に）。伸縮で範囲を決めた文節は、前の文節を伸縮しても同じ範囲のまま残る。ただし、伸ばした文節に取り込まれた文節と、縮めて手放した読みに続くすぐ後ろの文節、範囲の端を変換の表記の上で切れない文節は、作り直す。英語の文節や区間をまたいだ文節を伸縮して、後ろの英語と日本語の分かれ方が変わったときは、英語の側に入るか別の区間にかかった文節も作り直す |
| Shift+← / Shift+→ | 選ぶ文節を左 / 右へ移す。左端から左へ移すと右端、右端から右へ移すと左端を選ぶ |
| Enter | 表示しているとおりに確定する |
| Shift+Enter | 選んでいる文節までを確定し、残りは変換したまま次の文節を選ぶ |
| Esc / Backspace | 候補の窓を閉じる。窓が無ければ文節の選択をやめて、打っている途中の表示に戻る |
| F6 / F7 / F8 / F9 / F10 | 文節を選んでいる間は選んでいる文節を、打っている途中は未確定の文字列全体を、ひらがな / カタカナ / 半角カタカナ / 全角英数 / 打ったままにする |
| 英数 / かな | 英数モード / 日本語モードに切り替える |

- 打っている途中に矢印キーを押すと、Shift+Space を押さなくても最初の文節を選び、そのキーの動きをする
- 文の頭（入力の先頭か、句読点・記号の後）で 1 かなだけ打った時点では、変換せずにかなのまま見せる（`ki` は `き`）。1 かなの語は文節の候補から選ぶ
- 末尾に打った単独の `n` は、次に打つまで な行 か「ん」かが決まらないので、打ったまま見せる（`sounaruton` は `そうなるとn`、`nihon` は `にほn`）。「ん」で確定するときは `nn` と打つ。後ろに句読点を打てば「ん」になる。英語の語（`kotlin`）は打ったまま変わらない。Shift+Space で文節に区切るときは「ん」まで読む（`nihon` の候補に `日本`）

## 句読点と記号

- `,` `.` `?` `!` `~` `(` `:` `=` は、直前が日本語なら `、` `。` `？` `！` `〜` `（` `：` `＝` になり、直前が英語なら打ったまま残る。数字にはさまれた `.` `,` `:` `-`（`3.14` `1,000` `10:30` `2026-11-03`）は数の一部として打ったまま残る。文節を選んで候補からもう一方の形を選べる
- `)` は、組になる `(` と同じ形になる。組は入れ子を数えて決め、未確定の文字列に無ければ入力欄のカーソルより前の閉じていない括弧と組にする。組が無ければ `,` などと同じく直前で決まる。候補で括弧を選び直すと、組の括弧が 1 文字の文節なら、それも同じ形になる
- `[` `]` `/` は常に `「` `」` `・` になる。`zh` `zj` `zk` `zl` は `←` `↓` `↑` `→`、`z.` `z/` `z-` `z[` `z]` は `…` `・` `〜` `『` `』` になる。英字のまま打つときは英数モードにする
- アプリが打鍵に応じて補完する入力（絵文字の `:tada:`、`/` で始まるコマンド）は、入力メソッドを通さずにアプリへ届いたときだけ働くので、英数モードで打つ
- 入力欄の文字を入力メソッドに渡さないアプリ（Ghostty など）では、tugime で続けて確定した文字列を直前とする。tugime がアプリへ渡すキー（確定の後の Enter や矢印キーなど）を押すか、入力欄からフォーカスが外れると、直前は無いものに戻る

## 日本語と英語の見分け方

- 綴りの表で読めない並び（`gl` `pr` `str` など）を含む区間は英語になる
- ローマ字として読める英単語（`node` `site` など）は、文の前後から日本語か英語かを決める
- 綴りの表で最後まで読め、日本語の文の中に英字のまま書かれることの少ない綴り（`matte` など）と、読める 2 文字以下の綴り（`ie` など）は日本語になる
- 数字は前後の日本語と続けて変換する（`3kamo4kamoyasumu` は 3日も4日も休む）。数字と英字が混ざる綴りは、日本語として自然なら日本語、そうでなければ打ったまま残る（`3i` は 3位、`3a` と `i18n` は打ったまま）。数字の直後の `-` は長音にならない
- 大文字を含む綴りは綴りの表で読めないので、英語になる。`API` のように大文字で書く語は、大文字で打てば英語のまま残る
- 英語だけの文は英数モードで打つ。`go` のような 1 つのかなになる綴りは、日本語の側に読まれることがある
- ローマ字としても読める英語は、どちらに読まれるかがぶれる。英語の語の前後をスペースで区切って打つと、英語に読まれやすくなる（`homenomenuwokaeru` は 褒めのめぬを変える、`home no menu wo kaeru` は home の menu を 変える）。区切っても日本語に読まれる語は残る
- 1 語だけを英字で残すときは、Shift+Space で文節を選び、← / → でその語に合わせて F10 を押す。よく英語で打つ語は、tugime の辞書に `en` で登録する。登録した打鍵がそのまま 1 つの区間になる打ち方では英語になり、より長い日本語の読みが登録した打鍵をまたぐ打ち方（`kara` を登録して `asitakarahajimeru` は 明日から始める）では、ふだんの変換のままになる

見分けを誤る例は [現状の制限](limitations.md) にある。仕組みは [変換の仕組み](how-it-works.md) にある。

## tugime の辞書

既定の辞書に無い語や、別の表記で書きたい語は、tugime の辞書に打鍵で登録する。macOS の「ユーザ辞書」とは別の、tugime だけの辞書である。登録した語は、変換に入れた利用者の語 1 つと同じ強さで、日英の判定と変換に加わる。変換が登録した打鍵の範囲の前で文節を切り、後で語を切る打ち方では、範囲の中をどう切っても登録した語が出る（`sonohen	そのへん` を登録して `sonohenndeii` と打つと、その｜辺 ではなく「そのへんでいい」）。1 つの語が登録した打鍵の範囲をまたいで覆う打ち方（`kai	貝` を登録して `kaisya` と打つ）と、範囲が文節の途中から始まる打ち方（`nisi	西` を登録して `karenisiteha` と打つ）では、ふだんの変換（会社、彼にしては）のままになる。

辞書は 1 行 1 語のテキストのファイルで、打鍵、表記、区間の種類をタブで区切る。打鍵は、日本語モードで打つとおりの綴り（空白を除く英数字と記号）で書く。[句読点と記号](#句読点と記号)の句読点で始まる打鍵と、記号に変わる打鍵を含む打鍵は、打っても一致しないので読まない。途中に句読点を含む打鍵（`re:zero`）は読むが、句読点の直前が日本語に読まれると句読点で入力が切れるので、一致しない。区間の種類は `ja`（日本語区間）か `en`（英語区間）で、書かなければ、表記が ASCII だけなら `en`、それ以外は `ja` になる。同じ打鍵に別の表記を何語でも置ける。同じ打鍵と表記の組を 2 回書くと、2 つ目の行は読まない。空行と `#` で始まる行は読まない。

```
# 麻雀
mannzu	萬子
sonohen	そのへん
github	GitHub
cafe	Café
sake	鮭	ja
api	API	en
```

- `ja`: 打鍵を綴りの表でかなに読めれば（`mannzu` は まんず）、その読みの語として変換の候補にし、長い打鍵の途中（`ma-jannnomannzu`）でも効く。英語の語でもある打鍵（`sake`）も日本語の側に寄る。かなに読めない打鍵（`cafe`）は、打鍵とちょうど一致する区間をその語にする
- `en`: 打鍵とちょうど一致する区間を、日本語として読める綴りでも英語区間にし、その表記で表示する

どちらも、打ったままの綴りや元の変換は候補の窓に残る。

メニューバーの入力メニューの「tugime の辞書を編集…」か、「設定…」の窓の辞書の「編集…」で、辞書をテキストエディタ（プレーンテキストの既定のアプリ）で開く。辞書がまだ無ければ、書式の説明を書いた辞書を作ってから開く。

置き場所は次のとおり。開発版は `io.github.miyaoka.inputmethod.tugime.dev` の側に置く。開発版の設定の窓の「写す…」で、開発版の辞書を配布版の辞書で置き換えられる。

```
~/Library/Containers/io.github.miyaoka.inputmethod.tugime/Data/Library/Application Support/tugime/dictionary.tsv
```

保存すると、次に打ち始めたときから効く。読めない行は飛ばし、残りの行を使う。飛ばした行は、Console.app で tugime のログ（カテゴリ dictionary）に行番号つきで出る。
